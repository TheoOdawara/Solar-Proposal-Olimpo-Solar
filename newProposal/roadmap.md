# Roadmap do Projeto: Sistema de Propostas Comerciais Olimpo Solar

## 1. Levantamento e Planejamento
- Reunião inicial para alinhamento de requisitos e escopo
- Recebimento do design final do designer
- Definição da infraestrutura (servidor, hospedagem, banco de dados)
- Mapeamento dos campos e regras de negócio para cada tipo de proposta

**Estimativa:** 8h

## 2. Setup Inicial do Projeto
- Configuração do repositório e ambiente de desenvolvimento
- Setup do Vite + React + TypeScript + Tailwind + shadcn/ui
- Integração inicial com Supabase

**Estimativa:** 6h

## 3. Design System e Identidade Visual
- Implementação da nova paleta de cores e logo
- Criação dos novos ícones
- Componentização base (botões, inputs, cards, etc.)

**Estimativa:** 12h

## 4. Desenvolvimento do Front-End
- Reformulação completa das páginas da proposta
- Implementação do layout dividido (branco/azul)
- Responsividade e acessibilidade
- Integração com backend para dados dinâmicos

**Estimativa:** 24h

## 5. Funcionalidades de Proposta
- Geração de múltiplos tipos de proposta (padrão e eletroposto)
- Salvamento automático no histórico
- Marcação de proposta como "aceita"

**Estimativa:** 16h

## 6. Gerenciamento de Usuários
- Cadastro e autenticação de usuários (admin e vendedor)
- Controle de permissões

**Estimativa:** 10h

## 7. Métricas e Relatórios
- Implementação de dashboard de métricas
- Relatórios de propostas enviadas e aceitas

**Estimativa:** 8h

## 8. Testes e Validação
- Testes manuais e ajustes
- Validação de responsividade e UX

**Estimativa:** 6h

## 9. Deploy e Documentação
- Configuração de ambiente de produção
- Deploy no servidor/hospedagem escolhida
- Documentação final do sistema

**Estimativa:** 6h

---

**Total estimado:** 96h
