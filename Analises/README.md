# Pasta ./Analises

Aqui ficam as análises detalhadas por pasta/área do projeto, geradas durante a migração para a arquitetura Node.js + PostgreSQL + React/Tailwind.

Formato esperado para cada arquivo `analise<Area>.md`:

- Visão geral
- Arquivos críticos
- O que funciona / o que não funciona (evidências)
- Referências a `supabase` (ou outros nomes proibidos) — path + linha
- Ações recomendadas (patches/correções) com prioridade e risco
- Riscos / dependências externas
- Critério de aceitação
- Estimativa (horas)
- Anexos / evidências (logs do tsc/eslint, outputs)

Use estes templates para orientar alterações seguras e gerar o plano de ação final.
